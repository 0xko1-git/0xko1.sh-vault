# START HERE

## What this vault is

This is a clean starter. It contains no pentesting knowledge notes. You build the knowledge base yourself with one form.

The system has no manually maintained MOCs. The `_System/Graph` folder contains small graph hubs generated by the plugin; you do not edit them.

## First launch

If Obsidian displays Restricted Mode:

1. Open **Settings → Community plugins**.
2. Enable community plugins.
3. Enable **Pentest Note Manager**.

When the plugin works, the bottom status bar shows **Pentest notes: F6**.

## Daily workflow

1. Press `F6`.
2. Enter the title and choose the note type.
3. Select areas and platforms.
4. Optionally enter services, tools, and related notes.
5. Click **Create note**.
6. Write the note.

You never edit HOME, graph hubs, or another note just to register the new note.

## How real note-to-note links work

The important fields are:

- `tools` — links a technique or playbook to tool notes,
- `services` — links it to service notes,
- `related` — links any two notes that do not fit the fields above.

### Example: Nmap

Create the first note:

```text
Title: Nmap
Type: tool
Areas: enumeration
```

Then create:

```text
Title: Initial Nmap Scan
Type: technique
Areas: enumeration
Tools: Nmap
```

The plugin writes a real `[[Nmap]]` connection into `Initial Nmap Scan`. Therefore:

- Local Graph of `Initial Nmap Scan` shows `Nmap`,
- Local Graph of `Nmap` shows `Initial Nmap Scan` through the backlink,
- nothing is added manually to the Nmap note.

If the referenced note does not exist yet, the link is kept and resolves automatically after that note is created.

## Navigation

- `F6` — create a note from the correct template,
- `F7` — search names, aliases, areas, services, tools, platforms, and ports,
- `F8` — open HOME,
- `F9` — open Local Graph for the current note,
- `Ctrl+Shift+F` — full-text search for commands and fragments.

For HOME Local Graph use depth **2**. For an ordinary note, depth **1** is usually enough.

## Repair command

If you manually edit properties or move many files, run:

```text
Ctrl+P → Pentest Note Manager: Rebuild all automatic connections
```
