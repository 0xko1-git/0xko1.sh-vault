# Start Here

This is an empty Obsidian vault for reusable offensive-security knowledge and structured pentest workspaces.

## Core workflow

| Key | Action |
|---|---|
| `F6` | Pentest Manager |
| `F7` | Find anything |
| `F8` | Open HOME |
| `F9` | Open Local Graph |

## Knowledge

Use `F6 → New Knowledge Note` to create:

- Tool
- Service
- Technique
- Concept
- Playbook
- Lab
- Cheatsheet

Metadata such as `type`, `areas`, `services`, `tools`, `platforms`, and `related` is used for search, graph navigation, managed connections, and related-note suggestions.

## Pentests

Use `F6 → New Pentest`.

Supported project types:

- HTB Machine
- Exam
- Client Assessment
- Lab / Range
- Other

Projects are created under `40. Pentests/` with a Dashboard plus Scope, Logs, Loot, Hosts, Web, AD, Attack Path, Findings, Notes, Files, Payloads, Diagrams, and Screenshots.

Use:

- `F6 → Add Host` for Enumeration / Exploitation / Post-Exploitation host workspaces;
- `F6 → New Finding` for automatically numbered `H1/M1/L1` findings;
- `F6 → New Credential` for separate credential/hash loot notes;
- `F6 → Delete Pentest` to move an entire project to Obsidian Trash after exact-name confirmation.

## HOME

Press `F8`.

The HOME dashboard provides:

- Active Pentests
- Recent Findings
- searchable Knowledge Library
- Recently modified knowledge
- graph entry points

## Public-repository safety

The starter `.gitignore` excludes real pentest workspaces, attachments, archives, Trash, plugin backups, and third-party community plugins.

If you use this vault for real work, treat it as sensitive.
